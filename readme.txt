O projeto desenvolvido simula a tela de administrador de um Zoológico. Nele o usuário (um funcionário do Zoológico) tem acesso a um menu com as seguintes opções: 
1. Visualizar todos os animais cadastrados
2. Gerenciar os animais (abrindo um menu espécífico para isso)
3. Gerenciar as espécies (abrindo um menu espécífico para isso)
4. Sair do programa

A implementação usou o paradigma tecnológico da Orientação a Objetos, na linguagem Python e o banco de dados SQLite3. 

Usou-se as bibliotecas 'rich' para deixar o console mais agradável visualmente falando e a biblioteca 'os'para a limpeza do console após interações específicas. 

Para usar o projeto basta ter o python instalado na máquina e, a partir disso, executar no console: 

pip install rich

E pronto, já será suficiente. 

Observação: na pasta, envio o arquivo do banco de dados do SQLite com alguns animais e algumas espécies já cadastradas.
